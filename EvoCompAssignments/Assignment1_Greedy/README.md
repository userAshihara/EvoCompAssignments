# Evolutionary Computation — Puthyka Thearith ER-2355

Greedy heuristics for the selective TSP (choose half of the nodes, minimize distance + node costs).

This project uses C++ and Panda for the visualization.

run it by:
```bash
./assignment1
python3 plot.py
```

The program reads `../TSPA.csv` and `../TSPB.csv`, writes `results.txt`, then `plot.py` saves PNGs in `graphs/`.
